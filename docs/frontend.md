# Frontend «Резервика»

Рабочее пространство для бронирования помещений, оборудования, специалистов
и спецзон. Состав экранов опирается на [MVP и правила бронирования](mvp.md).

## Запуск и проверка

После установки зависимостей по [README](../README.md) запустите frontend
из корня репозитория:

```powershell
npm run dev -w frontend
```

Откройте [http://localhost:5173](http://localhost:5173).
Проверки: `npm run build -w frontend`, `npm run lint -w frontend`
и `npm run test -w frontend`.

## Экраны

| Путь | Содержимое |
| --- | --- |
| `/calendar` | Расписание ресурсов, поиск, категории, фильтр доступности и планы на день |
| `/resources` | Каталог, карточки, форма ресурса, группы и размещение |
| `/bookings` | Бронирования, статусы и подтверждение отмены всего набора ресурсов |
| `/approvals` | Очередь согласования и решения по отдельным ресурсам |
| `/team` | Участники, роли, приглашения и заявки на вступление |
| `/settings` | Организация, график работы и правила бронирования |
| `/organizations` | Организации пользователя, создание и поиск организации |
| `/profile` | Личные данные и настройки безопасности |
| `/login`, `/register` | Вход и регистрация |

Путь `/` открывает `/calendar`. Шапка содержит выбор роли, поиск, уведомления
и профиль. На узком экране основная навигация открывается отдельной панелью.

## Работа с календарём

Расписание показывает **19 октября 2026 года**, **09:00–19:00**,
часовой пояс организации — **Барнаул, UTC+7**.

Нажатие на свободное место сетки перемещает линию выбранного времени.
Линию можно перетаскивать за метку; начальное значение — 12:30,
шаг — 15 минут. При фокусе на метке стрелки ←/→ меняют время на 15 минут,
`Home` и `End` переходят к началу и концу дня.

Масштаб задаёт минимальную ширину часа: 80, 112 или 144 пикселя;
при широком окне часы растягиваются. Если расписание шире
панели, его можно прокручивать по горизонтали, тянуть мышью за свободную
сетку или сдвигать кнопками на час. На сенсорном экране работает обычная
горизонтальная прокрутка. Нажатие на бронь открывает её сведения.

Линия выбранного времени, фильтр доступности и время новой заявки независимы.
Фильтр изначально использует 09:00–10:00; начало должно быть раньше окончания
в пределах 09:00–19:00. Проверка учитывает графики ресурсов и обслуживание.
Пересечения считаются как полуинтервалы `[начало, окончание)`:
окончание одной брони ровно в начале другой не создаёт конфликт.

## Ресурсы и роли

Форма ресурса содержит название, тип, описание, расположение, ответственного,
способ согласования и график. Организация задаёт собственные группы;
один ресурс может входить в несколько групп. Группы не задают права доступа.
Размещение задаётся текстом и связью с помещением; эта связь сама по себе
не резервирует помещение. Для оборудования предусмотрена переносимость,
для специалиста — очный, удалённый или смешанный формат услуги.

| Роль | Возможности интерфейса |
| --- | --- |
| Сотрудник | Календарь, каталог, новая заявка и собственные бронирования |
| Ответственный | Возможности сотрудника и согласование закреплённых студии и камеры |
| Администратор | Все ресурсы, участники, настройки и общая очередь согласования |

Недоступные разделы убираются из навигации и закрываются при прямом переходе.
Отмена открывает подтверждение для всей заявки с общим интервалом и ресурсами.
Отмену своей заявки видят все роли, чужой — администратор.
Группы, размещение и отмена чужих заявок пока не меняют серверные требования
в [MVP](mvp.md); соответствующие правила согласуются отдельно.

## Оформление и доступность

Палитра: хвойный `#2e5b42`, фон `#f7f8f5`, лайм `#dcecaf`.
Состояния различаются цветом и текстом. Светлая и тёмная темы переключаются
в боковой панели; выбор сохраняется в `localStorage` (`rezervika-theme`).
Используется логотип из `docs/branding/rezervika-modular-small-ka-v1.png`,
копия — `frontend/public/brand/rezervika.png`. Предусмотрены ссылка перехода
к содержимому, видимый фокус, подписи кнопок и нативные модальные окна `dialog`.

## Текущее состояние

API ещё не подключён. Ресурсы и события заданы в исходниках; дата расписания
фиксирована. Локально работают навигация, окна, фильтры, выбор ресурсов,
роли и управление шкалой. Создание, отмена, согласование, приглашения,
авторизация и сохранение форм пока недоступны. Переключатель роли служит
для просмотра интерфейса; серверная проверка прав ещё требуется.
После перезагрузки сохраняется только тема оформления.
